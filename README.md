Бинарное дерево работающее со строками\n
сравнивает строки по алфавитному порядку
большие строки идут вправо малые влево
визуализация на мермаид
чтоб увидеть результат жмем 8(экспорт) и открывает tree.html
для запуска пишем команды
g++ main.cpp Tree/Tree.cpp Html/TreeHtml.cpp -o tree_app
.\tree_app.exe
