# Бинарное дерево для работы со строками

Данная программа реализует бинарное дерево поиска, которое сравнивает строки в алфавитном порядке:
* Большие строки (по алфавиту) идут **вправо**.
* Малые строки идут **влево**.

## Визуализация
Визуализация структуры дерева выполнена с помощью **Mermaid**. 
Чтобы увидеть результат работы:
1. Введите в меню программы цифру `8` (Экспорт).
2. Откройте появившийся в папке файл `tree.html` через любой веб-браузер.

## Как запустить

Для компиляции проекта через терминал введите команду:
1)g++ main.cpp Tree/Tree.cpp Html/TreeHtml.cpp -o tree_app.
2).\tree_app.exe.
